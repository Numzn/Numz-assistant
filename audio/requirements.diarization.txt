# Optional extra: pyannote-based speaker diarization for the Speech
# Intelligence batch pipeline (audio/speech_cli.py --diarize).
#
# Not part of the default install (audio/requirements.txt) — heavy,
# torch-based, and pyannote/speaker-diarization-3.1 is a gated model on
# HuggingFace. Before installing:
#   1. Create/sign in to a HuggingFace account: https://huggingface.co/join
#   2. Accept the model terms: https://huggingface.co/pyannote/speaker-diarization-3.1
#   3. Create a token: https://huggingface.co/settings/tokens
#   4. Set it as HF_TOKEN in .env.secrets or your shell environment
#
# Install with:
#   audio/.venv/bin/pip install -r audio/requirements.diarization.txt
